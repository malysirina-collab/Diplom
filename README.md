Сбор и анализ новостных данных (NLP)


Данная работа представляет собой способ сбора и анализа новостных данных с применением методов NLP для мониторинга общественного мнения, анализа новостей, выявления трендов.

Код строится на основе API новостных сервисов. Преимущество данного метода заключается в структурированном формате данныхых, меньшем риске блокировок, возможности фильтрации по категориям, дате и другим параметрам.
